````md
## Git Push and Pull

### Git Push

```bash
git push
```
````

- Sends local commits to the remote repository

Set upstream (first push):

```bash
git push -u origin <branch>
```

Use when:

- You want to upload your committed changes to GitHub

---

### Git Pull

```bash
git pull
```

- Fetches changes from remote
- Merges them into your current branch

Use when:

- You want the latest changes from the remote repo
